# fumiklea — проекты, собранные вручную

## Простыми словами

Двенадцать небольших проектов папками на Python, Java, C и JavaScript — от парсера с тестами и фрод-аналитики до игры про первую компьютерную моль и пиксельных сцен из «Кристины».

Это не первые мои проекты. Первые — сишные, они лежат в отдельном учебном репозитории. Здесь другое: почти всё написано более-менее вручную, (оно так или иначе никогда почти не может быть написано вручную, но здесь написано фрагментами) строка за строкой. Смысл именно в отработке техники.

Плата за это — скорость: вручную выходит медленнее, чем вместе с нейросетью, которую ты год обучал, зато каждая мелочь понятна и сделана осознанно. Каждый проект запускается из своей папки.
