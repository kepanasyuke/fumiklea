# fumiklea — первые проекты

## Простыми словами

Мой первый репозиторий: двенадцать небольших проектов папками на Python, Java, C и JavaScript — от парсера с тестами и фрод-аналитики до игры про первую компьютерную моль и анимаций в терминале.

Здесь я училась работать не «кодом в один файл», а с тестами, линтерами, `Makefile` и разделением на `src` и `tests`. Каждый проект запускается из своей папки.
