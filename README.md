# fumiklea — проекты, собранные вручную

## Простыми словами

Двенадцать небольших проектов папками на Python, Java, C и JavaScript — от парсера с тестами и фрод-аналитики до игры про первую компьютерную моль и пиксельных сцен из «Кристины».

Это не первые мои проекты. Первые — сишные, они лежат в отдельном учебном репозитории. Здесь другое: почти всё написано более-менее вручную, строка за строкой. Смысл именно в отработке техники — тесты, линтеры, `Makefile`, разделение на `src` и `tests`, аккуратная структура папок.

Плата за это — скорость: вручную выходит медленнее, чем на готовых заготовках, зато каждая мелочь понятна и сделана осознанно. Каждый проект запускается из своей папки.
